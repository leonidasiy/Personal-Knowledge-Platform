Axis one

Visual theme

All three themes support System, Light, and Dark appearance modes. Theme changes color, typography emphasis, border treatment, and motion intensity without changing information architecture.

Balanced

Studio Signal

Mineral surfaces with precise teal, coral, and gold signals for sustained focus.

  • Restrained motion
  • Best cross-domain fit
  • Quietest long-session palette

Editorial

Collection Index

Cobalt, tomato, and gold frame artwork and provenance like liner notes or an archive.

  • Strongest source presentation
  • Square editorial treatment
  • Moderate motion

Energetic

Learning Pulse

Brighter blue, red, yellow, and green state accents with tactile confirmation.

  • Most visible feedback
  • Expressive motion
  • No points or streaks

Axis two

Workspace layout

Every layout keeps Feed and Review as exclusive routes. Layout controls density, supporting rails, and media composition; it never places a quiz inside a study card.

Recommended

Guided Stack

One focused column on every route, with supporting context placed directly after the main activity.

  • Lowest cognitive load
  • Natural mobile behavior
  • Best for deep study

Contextual

Split Desk

Main activity plus a supporting context or review-queue rail on wide screens.

  • 58/42 desktop workspace
  • Rail stacks on mobile
  • Best context visibility

Dense

Compact Index

Horizontal study media and a queue-first review workspace for fast scanning.

  • Highest information density
  • Efficient repeated use
  • Stacks below tablet width
