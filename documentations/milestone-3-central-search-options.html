Fixed implementation choices

  • One labelled Discover search field with native expandable filters.
  • Default result limit 10; selectable 5, 10, or 20; aggregate limit is applied after canonical deduplication.
  • YouTube query is normalized and augmented on the Worker, then filtered by a versioned educational metadata policy.
  • Library search remains local to saved D1 sources.
  • Reclaim space first. Stop for a measured budget revision if fixed budgets cannot pass without compromise.
